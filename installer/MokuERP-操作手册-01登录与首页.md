# 第一章 系统登录与首页仪表盘

## 1.1 系统登录

### 1.1.1 打开系统

启动 MokuERP 后，浏览器将自动打开登录页面 `http://localhost:9999`。

### 1.1.2 登录界面

登录页面包含以下元素：

- **租户**：选择或输入租户名称，默认租户为 `Moku`
- **用户名**：输入登录账号，默认管理员账号为 `admin`
- **密码**：输入登录密码，默认密码为 `123456`
- **记住密码**：勾选后下次登录自动填充
- **登录按钮**：点击完成登录

### 1.1.3 首次登录建议

首次登录后，强烈建议：
1. 点击右上角头像 - **修改密码**
2. 进入 **系统管理 - 用户管理**，完善用户信息
3. 进入 **系统管理 - 角色管理**，配置角色权限

## 1.2 首页仪表盘

登录成功后默认进入首页仪表盘，展示系统核心数据统计。

### 1.2.1 数据卡片区

顶部显示 12 个核心指标卡片：

| 卡片名称 | 说明 |
|----------|------|
| 今日销售 | 统计今日销售单据总金额 |
| 今日零售 | 统计今日零售单据总金额 |
| 今日采购 | 统计今日采购单据总金额 |
| 本月累计销售 | 统计本月销售单据总金额 |
| 本月累计零售 | 统计本月零售单据总金额 |
| 本月累计采购 | 统计本月采购单据总金额 |
| 昨日销售 | 统计昨日销售单据总金额 |
| 昨日零售 | 统计昨日零售单据总金额 |
| 昨日采购 | 统计昨日采购单据总金额 |
| 今年累计销售 | 统计本年度销售单据总金额 |
| 今年累计零售 | 统计本年度零售单据总金额 |
| 今年累计采购 | 统计本年度采购单据总金额 |

### 1.2.2 图表统计区

中部三个柱状图，分别展示：
- **销售统计**：往前 6 个月每月销售总金额
- **零售统计**：往前 6 个月每月零售总金额
- **采购统计**：往前 6 个月每月采购总金额

### 1.2.3 底部信息区

- **服务到期时间**：显示当前租户服务有效期
- **授权用户数量**：显示已用/总授权用户数
- **版权信息**：系统版本号
