# 项目总述
* 陌库ERP（英文名：MokuERP）是一款开源的国产ERP系统
* 目前包含进销存、财务、生产等功能模块

# 开发初衷
* 为中小企业提供开源好用的ERP软件，降低企业的信息化成本
* 个人开发者可以进行二次开发，加快完成开发任务
* 初学JAVA的小伙伴可以下载源代码来进行学习交流

# 技术框架
* 核心框架：SpringBoot 2.0.0
* 持久层框架：Mybatis 1.3.2
* 日志管理：SLF4J 1.7
* 前端框架：Vue 2.6.10
* UI框架: Ant-Design-Vue 1.5.2
* 模板框架: Jeecg-Boot 2.2.0
* 项目管理框架: Maven 3.2.3

# 开发环境
建议开发者使用以下环境，可以避免版本带来的问题
* IDE: IntelliJ IDEA 2019.2+和JetBrains WebStorm 2019.3+
* DB: Mysql 5.7.33
* JDK: JDK 1.8
* Node: Node 16.16.0
* Maven: Maven 3.2.3+
* Redis: 6.2.1
* Nginx: 1.12.2
