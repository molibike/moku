# 第二章 通用界面说明

系统大多数列表页面采用统一的布局模式，掌握通用操作即可熟练使用各模块。

---

## 2.1 页面布局

```
+--------------------------------------------------+
|  左侧菜单栏    |   顶部面包屑导航 + 页签栏        |
|                +----------------------------------+
|  [资料管理]    |   搜索区域                        |
|  [单据管理]    |  [查询] [重置] [展开]             |
|  [财务管理]    +----------------------------------+
|  [报表中心]    |   操作按钮区域                    |
|  [系统管理]    |  [新增] [删除] [导入] ...         |
|                +----------------------------------+
|                |   数据表格区域                    |
|                |  条码  名称  规格 ... [操作]     |
|                +----------------------------------+
|                |   分页控件                        |
|                |  < 1 2 3 ... 10 > 共100条         |
+--------------------------------------------------+
```

---

## 2.2 搜索区域

每个列表页面顶部均设有搜索区域，通用操作如下：

- **查询**：输入或选择搜索条件后，点击 **"查询"** 按钮筛选数据
- **重置**：点击 **"重置"** 按钮清空所有搜索条件，恢复默认列表
- **展开/收起**：点击 **"展开"** 显示更多搜索条件，点击 **"收起"** 隐藏次要条件
- **回车搜索**：在输入框中按 `Enter` 键可直接触发查询

**常用搜索条件类型：**
- 文本输入框：支持模糊匹配（如商品名称、条码、规格）
- 下拉选择框：从预定义选项中选择（如状态、仓库）
- 树形选择器：用于选择分类层级（如商品类别）
- 日期选择器：选择时间范围

---

## 2.3 操作按钮区域

列表上方的操作按钮，各模块略有差异，常见按钮如下：

| 按钮 | 说明 | 使用前提 |
|------|------|----------|
| **新增** | 打开新增弹窗，录入新数据 | 需具有新增权限 |
| **删除** | 批量删除选中的记录 | 需先勾选表格左侧复选框 |
| **启用** | 批量启用选中的禁用记录 | 需先勾选表格左侧复选框 |
| **禁用** | 批量禁用选中的启用记录 | 需先勾选表格左侧复选框 |
| **导入** | 从 Excel 文件批量导入数据 | 需下载模板后按格式填写 |
| **导出** | 将当前列表数据导出为 Excel | 直接导出，无需勾选 |
| **批量编辑** | 批量修改选中记录的公共字段 | 需先勾选表格左侧复选框 |
| **修正库存** | 批量修正选中商品的当前库存 | 仅商品管理模块 |
| **修正成本** | 批量修正选中商品的当前成本 | 仅商品管理模块 |
| **列设置** | 自定义表格显示的列 | 点击后勾选/取消列名 |

---

## 2.4 数据表格区域

表格展示查询结果，通用操作：

- **表头排序**：点击列标题可对该列进行升序/降序排序
- **行选择**：点击每行左侧复选框，可多选进行批量操作
- **行内操作**：每行右侧显示 **"编辑"**、**"删除"** 等操作链接
- **分页导航**：底部显示总条数、每页条数选择、页码切换
- **列宽调整**：拖拽列标题右侧边框可调整列宽
- **图片预览**：点击商品图片可放大查看

---

## 2.5 新增/编辑弹窗

点击 **"新增"** 或行内 **"编辑"** 后打开弹窗表单，通用操作：

- **必填项**：标有红色 `*` 的字段为必填项
- **保存**：填写完成后点击 **"确定"** 保存数据
- **取消**：点击 **"取消"** 或弹窗右上角 `X` 关闭弹窗，不保存
- **表单验证**：如有必填项未填或格式错误，会提示红色错误信息

---

## 2.6 删除确认

点击 **"删除"** 时，系统会弹出确认对话框：
- 点击 **"确定"** 执行删除
- 点击 **"取消"** 放弃删除
- **注意**：部分删除为逻辑删除（标记为删除），部分为物理删除（不可恢复），请谨慎操作
