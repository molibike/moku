# 第七章 系统管理

系统管理模块用于配置组织架构、用户权限、基础档案等系统级数据。

---

## 7.1 机构管理

**路径**：`左侧菜单 - 系统管理 - 机构管理`

### 7.1.1 功能说明

设置企业的组织架构，支持多级部门/分支机构管理。

### 7.1.2 操作说明

- **新增**：添加新机构/部门
- **编辑**：修改机构名称、排序等
- **删除**：删除无下级机构和无用户的机构

---

## 7.2 用户管理

**路径**：`左侧菜单 - 系统管理 - 用户管理`

### 7.2.1 搜索条件

| 条件 | 说明 |
|------|------|
| 用户账号 | 登录用户名 |
| 用户姓名 | 真实姓名 |
| 状态 | 正常 / 禁用 |
| 机构 | 所属部门 |

### 7.2.2 操作按钮

- **新增**：创建新用户
- **编辑**：修改用户信息、重置密码、分配角色
- **删除**：删除用户
- **启用/禁用**：控制用户登录状态

### 7.2.3 新增用户弹窗字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 登录账号 | 是 | 用户名，不可重复 |
| 登录密码 | 是 | 初始密码 |
| 用户姓名 | 是 | 真实姓名 |
| 手机号 | 否 | 联系方式 |
| 机构 | 是 | 所属部门 |
| 角色 | 是 | 分配角色（可多选） |
| 状态 | 是 | 正常 / 禁用 |

## 7.3 角色管理

**路径**：`左侧菜单 - 系统管理 - 角色管理`

### 7.3.1 功能说明

定义系统中的角色（如：管理员、采购员、销售员、财务等），并为每个角色配置操作权限。

### 7.3.2 操作说明

- **新增**：创建新角色
- **编辑**：修改角色信息和权限
- **删除**：删除未被用户使用的角色
- **权限配置**：
  1. 点击角色行内的 **"权限配置"**
  2. 在弹出的权限树中勾选该角色可访问的菜单和功能
  3. 勾选 **"查看"** 权限：可打开对应页面
  4. 勾选 **"新增"** 权限：可执行新增操作
  5. 勾选 **"编辑"** 权限：可执行编辑操作
  6. 勾选 **"删除"** 权限：可执行删除操作
  7. 勾选 **"导出"** 权限：可执行导出操作
  8. 点击 **"确定"** 保存权限配置
