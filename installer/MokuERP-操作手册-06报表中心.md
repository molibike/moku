# 第六章 报表中心

报表中心提供多维度的数据统计和分析，所有报表页面均采用统一的查询界面。

---

## 6.1 报表通用操作

每个报表页面均包含：

- **搜索条件**：时间范围、商品、仓库、往来单位等筛选条件
- **查询按钮**：点击刷新报表数据
- **导出按钮**：将报表数据导出为 Excel
- **表格/图表展示**：以表格或图表形式呈现数据

**操作步骤**：
1. 选择报表的时间范围（开始日期 - 结束日期）
2. 根据需要选择其他筛选条件（商品、仓库、往来单位等）
3. 点击 **"查询"** 按钮刷新报表数据
4. 如需导出，点击 **"导出"** 按钮，选择保存位置

## 6.2 入库明细

**路径**：`左侧菜单 - 报表中心 - 入库明细`

### 6.2.1 功能说明

查询所有入库单据的商品明细记录，可按日期、商品、仓库等条件筛选。

### 6.2.2 展示字段

| 字段 | 说明 |
|------|------|
| 单据编号 | 关联入库单号 |
| 单据日期 | 入库日期 |
| 仓库 | 入库仓库 |
| 商品条码 | 商品编码 |
| 商品名称 | 商品名称 |
| 规格 | 商品规格 |
| 单位 | 计量单位 |
| 入库数量 | 本次入库数量 |
| 入库单价 | 入库单价 |
| 入库金额 | 数量 x 单价 |

### 6.2.3 搜索条件

| 条件 | 说明 |
|------|------|
| 单据日期 | 查询的日期范围 |
| 仓库 | 筛选指定仓库 |
| 商品 | 筛选指定商品 |
| 供应商 | 筛选指定供应商 |

## 6.7 库存预警

**路径**：`左侧菜单 - 报表中心 - 库存预警`

### 6.7.1 功能说明

展示低于安全库存或超过上限库存的商品，帮助企业及时补货或处理积压。

### 6.7.2 预警类型

| 类型 | 说明 | 建议操作 |
|------|------|----------|
| 库存不足 | 当前库存低于安全库存下限 | 及时采购补货 |
| 库存积压 | 当前库存超过库存上限 | 促销清理或调拨 |
