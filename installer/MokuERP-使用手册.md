## 一、系统简介

MokuERP 是一款面向中小企业的进销存管理系统，基于 Spring Boot + Vue 技术栈开发。本安装包为 Windows 单机版，集成了完整的运行环境（JDK、MySQL、Redis），用户无需额外安装任何依赖即可直接使用。

**主要功能：**
- 商品管理、客户管理、供应商管理
- 采购入库、销售出库、库存盘点
- 财务报表、数据统计分析
- 多租户支持、权限管理

## 二、运行环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 7 / 8 / 10 / 11（64位） |
| 内存 | 4GB 及以上（推荐 8GB） |
| 硬盘空间 | 2GB 及以上可用空间 |
| 浏览器 | Chrome / Edge / Firefox / 360 极速模式 |
| 网络 | 不需要互联网连接（纯单机运行） |

**端口占用提示：**
安装和运行期间需要确保以下端口未被占用：
- `3306` — MySQL 数据库服务
- `6379` — Redis 缓存服务
- `9999` — Java 后端服务

## 三、安装步骤

### 1. 获取安装包

安装包文件名为 `MokuERP-Setup.exe`，文件大小约 200MB。

### 2. 运行安装程序

1. 双击 `MokuERP-Setup.exe`
2. 系统可能弹出"用户账户控制（UAC）"提示，请点击 **"是"** 以允许安装
3. 安装向导将显示中文界面

### 3. 选择安装目录

- 默认安装路径：`D:\MokuERP`
- 建议保持默认路径，避免路径中包含中文或空格
- 确保目标磁盘有至少 2GB 的可用空间

### 4. 完成安装

- 勾选"创建桌面快捷方式"（推荐）
- 安装完成后，勾选"立即启动 MokuERP"即可自动运行
- 桌面上会出现 **MokuERP** 图标

## 四、启动与使用

### 方式一：通过桌面快捷方式启动

1. 双击桌面上的 **MokuERP** 图标
2. 系统将自动依次启动以下服务：
   - MySQL 数据库服务
   - Redis 缓存服务
   - Java 后端服务
3. 服务启动完成后，浏览器将自动打开并访问系统

### 方式二：从开始菜单启动

1. 点击 Windows 开始菜单
2. 找到 **MokuERP** 文件夹
3. 点击 **MokuERP** 启动

### 系统访问地址

浏览器会自动打开以下地址：
```
http://localhost:9999
```

### 默认登录信息

| 项目 | 内容 |
|------|------|
| 租户 | Moku |
| 账号 | admin |
| 密码 | 123456 |

首次登录后，建议立即修改默认密码。

### 文件上传目录

系统上传的文件保存在安装目录下的 `upload` 文件夹中。

## 五、停止服务

### 方式一：使用停止程序

1. 点击开始菜单中的 **MokuERP** 文件夹
2. 选择 **"停止 MokuERP"**
3. 系统将依次停止 Java 后端、Redis 和 MySQL 服务

### 方式二：关机时自动停止

直接关闭或重启电脑时，所有后台服务会自动停止，数据不会丢失。

## 六、卸载软件

### 通过控制面板卸载

1. 打开 Windows 控制面板 → 程序和功能
2. 找到 **MokuERP**
3. 点击 **卸载**
4. 卸载程序会自动停止所有运行中的服务

### 手动删除

如果控制面板卸载失败，可手动删除安装目录（默认 `D:\MokuERP`）。

**注意：** 卸载前请务必备份数据库中的重要数据。数据文件位于安装目录的 `tools\mysql\data` 文件夹中。

## 七、常见问题

### Q1：启动时提示端口被占用

**现象：** 启动后弹窗提示服务启动失败，或浏览器无法访问系统。

**解决：**
1. 检查是否有其他程序占用了 3306、6379 或 9999 端口
2. 打开任务管理器，查看是否有其他 MySQL、Redis 或 Java 进程在运行
3. 关闭占用端口的程序后重新启动 MokuERP

### Q2：浏览器没有自动打开

**现象：** 启动器提示启动成功，但浏览器未自动弹出。

**解决：**
1. 手动打开浏览器，访问 `http://localhost:9999`
2. 如果页面无法访问，请等待 1-2 分钟后重试（首次启动可能需要更长时间）
3. 检查安装目录下的 `logs\backend.log` 查看是否有错误信息

### Q3：忘记登录密码

**解决：**
- 默认密码为 `123456`
- 如已修改且忘记，需要联系管理员或通过数据库直接重置（需一定技术基础）

### Q4：系统运行卡顿

**建议：**
1. 确保电脑内存不低于 4GB
2. 关闭不必要的其他程序
3. 定期清理 `logs` 目录下的日志文件

### Q5：数据如何备份

**方法：**
1. 停止 MokuERP 服务
2. 复制安装目录下 `tools\mysql\data` 文件夹到安全位置
3. 需要恢复时，停止服务后将备份的数据文件夹覆盖回原位置
