# 第四章 单据管理

单据管理是系统的核心业务模块，处理采购、销售、零售、调拨、组装等业务流程。所有单据页面采用统一的布局模式。

---

## 4.1 单据通用界面说明

每个单据列表页面均包含以下区域：

### 4.1.1 搜索区域

| 常用条件 | 说明 |
|----------|------|
| 单据编号 | 单据流水号查询 |
| 单据日期 | 选择日期范围 |
| 供应商/客户 | 选择关联往来单位 |
| 仓库 | 选择仓库筛选 |
| 状态 | 待审核 / 已审核 / 部分入库 / 全部入库 等 |
| 关键词 | 按商品名称、条码等模糊查询 |

### 4.1.2 操作按钮

| 按钮 | 说明 |
|------|------|
| **新增** | 打开单据录入弹窗 |
| **删除** | 删除选中的未审核单据 |
| **审核** | 审核选中的待审核单据 |
| **反审核** | 撤销已审核单据的审核状态 |
| **导出** | 导出单据列表 |

### 4.1.3 单据状态说明

| 状态 | 说明 |
|------|------|
| 待审核 | 单据已录入，等待审核确认 |
| 已审核 | 单据已审核，库存/财务数据已生效 |
| 部分入库/出库 | 单据已部分执行 |
| 全部入库/出库 | 单据已完全执行 |

### 4.1.4 单据弹窗界面

新增/编辑单据时打开弹窗，一般包含以下区域：

```
+--------------------------------------------------+
| 单据主表信息（单号、日期、供应商、仓库等）          |
+--------------------------------------------------+
| 商品明细表格                                      |
|  条码  名称  规格  数量  单价  金额  [删]          |
|  [+ 添加商品]  合计金额：XXXX                     |
+--------------------------------------------------+
| 备注文本框                                        |
+--------------------------------------------------+
|  [确定]  [取消]                                   |
+--------------------------------------------------+
```

**添加商品明细操作**：
1. 点击 **"+ 添加商品"** 或表格中的 **"新增一行"**
2. 点击商品列的输入框，弹出商品选择窗口
3. 搜索并选中商品，自动带出条码、规格、默认价格
4. 修改数量、单价（如需要）
5. 系统会自动计算金额（数量 x 单价）
6. 点击 **"确定"** 保存单据

---

## 4.2 采购申请

**路径**：`左侧菜单 - 单据管理 - 采购申请`

### 4.2.1 功能说明

向供应商发起采购意向申请，通常作为采购流程的第一步。采购申请不实际影响库存。

### 4.2.2 业务流程

采购申请 -> 采购订单 -> 采购入库 -> 采购退货

---

## 4.3 采购订单

**路径**：`左侧菜单 - 单据管理 - 采购订单`

### 4.3.1 功能说明

向供应商下达正式采购订单。订单确认后，可据此进行采购入库。

### 4.3.2 主表字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 供应商 | 是 | 选择供应商 |
| 单据日期 | 是 | 订单日期 |
| 单据编号 | 是 | 系统自动生成 |
| 仓库 | 是 | 入库仓库 |
| 备注 | 否 | 订单备注 |

### 4.3.3 明细操作

- 添加商品明细，输入数量和单价
- 支持从 **采购申请** 直接生成采购订单
- 订单审核后，可在 **采购入库** 中引用此订单进行入库

---

## 4.4 采购入库

**路径**：`左侧菜单 - 单据管理 - 采购入库`

### 4.4.1 功能说明

采购的商品实际入库时录入此单据，审核后会增加库存数量和金额。

### 4.4.2 主表字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 供应商 | 是 | 选择供应商 |
| 仓库 | 是 | 入库仓库 |
| 单据日期 | 是 | 入库日期 |
| 单据编号 | 是 | 系统自动生成 |
| 关联订单 | 否 | 可关联采购订单，自动带出订单商品 |
| 备注 | 否 | 入库备注 |

### 4.4.3 操作说明

1. 点击 **"新增"** 打开入库单录入窗口
2. 选择供应商和仓库
3. 添加商品明细：点击 **"+ 添加商品"**，选择商品、输入入库数量和单价
4. 点击 **"确定"** 保存为待审核状态
5. 勾选单据，点击 **"审核"**，库存增加，单据生效

---

## 4.5 采购退货

**路径**：`左侧菜单 - 单据管理 - 采购退货`

### 4.5.1 功能说明

将已入库的商品退回给供应商，审核后减少库存。

### 4.5.2 操作说明

- 可选择关联的 **采购入库单**，自动带出原入库商品
- 输入退货数量（不能超过原入库数量）
- 审核后库存减少

---

## 4.6 销售订单

**路径**：`左侧菜单 - 单据管理 - 销售订单`

### 4.6.1 功能说明

接收客户订货时录入，作为销售出库的前置单据。

### 4.6.2 主表字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 客户 | 是 | 选择客户 |
| 仓库 | 是 | 发货仓库 |
| 单据日期 | 是 | 订单日期 |
| 备注 | 否 | 订单备注 |

---

## 4.7 销售出库

**路径**：`左侧菜单 - 单据管理 - 销售出库`

### 4.7.1 功能说明

销售商品出库时录入，审核后减少库存。

### 4.7.2 主表字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 客户 | 是 | 选择客户 |
| 仓库 | 是 | 出库仓库 |
| 单据日期 | 是 | 出库日期 |
| 关联订单 | 否 | 可关联销售订单 |
| 备注 | 否 | 出库备注 |

### 4.7.3 操作说明

1. 点击 **"新增"**
2. 选择客户和仓库
3. 添加商品明细，输入出库数量，系统自动带出默认销售价
4. 点击 **"确定"** 保存
5. 勾选单据，点击 **"审核"** 完成出库

---

## 4.8 销售退货

**路径**：`左侧菜单 - 单据管理 - 销售退货`

### 4.8.1 功能说明

客户退回已售商品时录入，审核后增加库存。

---

## 4.9 零售出库

**路径**：`左侧菜单 - 单据管理 - 零售出库`

### 4.9.1 功能说明

面向散客的零售业务出库，与"销售出库"区别是不关联客户档案，适合门店收银场景。

### 4.9.2 操作说明

- 无需选择客户，直接录入商品和金额
- 支持按零售价自动带出价格

---

## 4.10 零售退货

**路径**：`左侧菜单 - 单据管理 - 零售退货`

### 4.10.1 功能说明

零售商品退货时录入。

---

## 4.11 其他入库

**路径**：`左侧菜单 - 单据管理 - 其他入库`

### 4.11.1 功能说明

非采购来源的商品入库，如：赠送入库、盘点盈余入库、初始库存录入等。

---

## 4.12 其他出库

**路径**：`左侧菜单 - 单据管理 - 其他出库`

### 4.12.1 功能说明

非销售原因的商品出库，如：赠送出库、盘点亏损出库、损耗出库等。

---

## 4.13 调拨出库

**路径**：`左侧菜单 - 单据管理 - 调拨出库`

### 4.13.1 功能说明

将商品从一个仓库调拨到另一个仓库。审核后，出库仓库库存减少，入库仓库库存增加。

### 4.13.2 主表字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 调出仓库 | 是 | 商品调出仓库 |
| 调入仓库 | 是 | 商品调入仓库 |
| 单据日期 | 是 | 调拨日期 |

---

## 4.14 组装单

**路径**：`左侧菜单 - 单据管理 - 组装单`

### 4.14.1 功能说明

将多个子商品组装成一个成品，适用于生产加工型企业。审核后子商品库存减少，成品库存增加。

### 4.14.2 操作说明

- 选择组装后的 **成品商品**
- 选择组装所需的 **子商品明细**
- 设置组装数量
- 审核后系统自动调整各商品库存

---

## 4.15 拆卸单

**路径**：`左侧菜单 - 单据管理 - 拆卸单`

### 4.15.1 功能说明

将成品拆卸为多个子商品，与组装单相反。审核后成品库存减少，子商品库存增加。
