# 第三章 资料管理

资料管理是系统的基础数据维护模块，包含商品信息、商品分类、商品属性等。

---

## 3.1 商品管理

**路径**：`左侧菜单 - 资料管理 - 商品管理`

### 3.1.1 功能说明

管理企业的商品档案，包括基本信息、价格、库存等。

### 3.1.2 搜索条件

| 条件 | 类型 | 说明 |
|------|------|------|
| 类别 | 树形选择 | 按商品分类筛选 |
| 关键词 | 文本输入 | 支持条码、名称、规格、型号模糊查询 |
| 颜色 | 文本输入 | 按颜色筛选 |
| 状态 | 下拉选择 | 启用 / 禁用 |
| 序列号 | 下拉选择 | 有 / 无序列号管理 |
| 批号 | 下拉选择 | 有 / 无批号管理 |
| 仓位货架 | 文本输入 | 按仓位货架筛选 |
| 扩展信息 | 文本输入 | 按扩展信息筛选 |
| 基础重量 | 数值输入 | 按基础重量筛选 |
| 保质期 | 数值输入 | 按保质期天数筛选 |
| 备注 | 文本输入 | 按备注内容筛选 |

### 3.1.3 表格列说明

| 列名 | 说明 |
|------|------|
| 操作 | 编辑、删除 |
| 图片 | 商品图片（点击可放大） |
| 条码 | 商品条形码/编码 |
| 名称 | 商品名称 |
| 规格 | 商品规格描述 |
| 型号 | 商品型号 |
| 颜色 | 商品颜色 |
| 类别 | 所属商品类别 |
| 扩展信息 | 扩展属性信息 |
| 单位 | 计量单位 |
| 基础重量 | 商品基础重量 |
| 保质期 | 保质期天数 |
| 库存 | 当前库存数量 |
| 采购价 | 采购参考价格 |
| 零售价 | 零售参考价格 |
| 销售价 | 批发/销售参考价格 |
| 最低售价 | 最低销售价格限制 |
| 仓位货架 | 存放位置 |
| 备注 | 备注信息 |
| 状态 | 启用 / 禁用 |

### 3.1.4 操作按钮

- **新增**：打开商品新增弹窗
- **删除**：删除选中的商品记录
- **启用/禁用**：批量修改商品状态
- **导入**：通过 Excel 批量导入商品，需先下载模板
- **导出**：导出商品列表到 Excel
- **批量编辑**：批量修改选中商品的公共字段
- **修正库存**：根据出入库记录重新计算当前库存
- **修正成本**：根据出入库记录重新计算当前成本
- **列设置**：自定义显示的列

### 3.1.5 新增/编辑商品

弹窗表单字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 商品类别 | 是 | 选择商品所属分类 |
| 商品名称 | 是 | 输入商品名称 |
| 条码 | 否 | 商品条形码，可留空自动生成 |
| 规格 | 否 | 商品规格描述 |
| 型号 | 否 | 商品型号 |
| 颜色 | 否 | 商品颜色 |
| 单位 | 是 | 计量单位（如：个、箱、千克） |
| 采购价 | 否 | 参考采购价格 |
| 零售价 | 否 | 参考零售价格 |
| 销售价 | 否 | 参考批发/销售价格 |
| 最低售价 | 否 | 价格下限 |
| 基础重量 | 否 | 商品重量（用于物流计算） |
| 保质期 | 否 | 保质期天数 |
| 仓位货架 | 否 | 仓库货架位置 |
| 序列号管理 | 否 | 开启后该商品支持序列号追踪 |
| 批号管理 | 否 | 开启后该商品支持批号/批次追踪 |
| 图片 | 否 | 上传商品图片 |
| 备注 | 否 | 备注说明 |
| 状态 | 是 | 启用 / 禁用 |

## 3.2 商品类别

**路径**：`左侧菜单 - 资料管理 - 商品类别`

### 3.2.1 功能说明

对商品进行分类管理，支持多级分类（树形结构）。

### 3.2.2 操作说明

- **新增**：选择父级类别后，点击 **"新增"** 添加子类别
- **编辑**：点击行内 **"编辑"** 修改类别名称、排序等
- **删除**：删除无子类别且无商品关联的类别
- **展开/折叠**：点击类别前的 `+` / `-` 图标展开或折叠子类别

### 3.2.3 字段说明

| 字段 | 说明 |
|------|------|
| 类别名称 | 分类名称 |
| 上级类别 | 父级分类 |
| 排序 | 显示顺序，数字越小越靠前 |

---

## 3.3 商品属性

**路径**：`左侧菜单 - 资料管理 - 商品属性`

### 3.3.1 功能说明

定义商品的扩展属性字段，如"产地"、"品牌"、"材质"等，方便在商品信息中灵活扩展。

### 3.3.2 操作说明

- **新增**：添加新的属性名称
- **编辑**：修改属性名称
- **删除**：删除未使用的属性

---

## 3.4 商品属性值

**路径**：`左侧菜单 - 资料管理 - 商品属性值`

### 3.4.1 功能说明

为已定义的商品属性设置可选值，如属性"颜色"的值可以是"红"、"蓝"、"黑"。
