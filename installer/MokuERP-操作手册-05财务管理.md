# 第五章 财务管理

财务管理模块处理企业的日常收支、转账等业务。

---

## 5.1 收入单

**路径**：`左侧菜单 - 财务管理 - 收入`

### 5.1.1 功能说明

记录企业日常经营收入，如：销售收款、服务收入、其他收入等。

### 5.1.2 主表字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 账户 | 是 | 收款账户 |
| 金额 | 是 | 收入金额 |
| 往来单位 | 否 | 关联客户或供应商 |
| 经手人 | 否 | 经办人员 |
| 单据日期 | 是 | 收入日期 |
| 备注 | 否 | 收入说明 |

### 5.1.3 操作说明

1. 点击 **"新增"** 打开收入单弹窗
2. 选择收款账户，输入收入金额
3. 选择关联往来单位（如销售对应的客户）
4. 选择经手人
5. 填写备注说明
6. 点击 **"确定"** 保存单据

---

## 5.3 转账单

**路径**：`左侧菜单 - 财务管理 - 转账`

### 5.3.1 功能说明

记录企业内部账户之间的资金划转。

### 5.3.2 主表字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 转出账户 | 是 | 资金转出账户 |
| 转入账户 | 是 | 资金转入账户 |
| 金额 | 是 | 转账金额 |
| 单据日期 | 是 | 转账日期 |
| 备注 | 否 | 转账说明 |

### 5.3.3 操作说明

1. 点击 **"新增"**
2. 选择转出账户和转入账户（不能为同一账户）
3. 输入转账金额
4. 填写备注（如：备用金划拨）
5. 点击 **"确定"** 保存

---

## 5.4 收预付款

**路径**：`左侧菜单 - 财务管理 - 收预付款`

### 5.4.1 功能说明

记录客户预付定金或供应商预付货款。

### 5.4.2 操作说明

- **收预付款**：客户提前支付货款时录入
- **付预付款**：向供应商提前支付货款时录入
- 选择往来单位、账户、金额后保存

---

## 5.5 项目收入

**路径**：`左侧菜单 - 财务管理 - 项目收入`

### 5.5.1 功能说明

按项目维度记录收入，适用于项目制经营的企业。

### 5.5.2 操作说明

- 选择项目名称
- 选择收款账户、输入金额
- 填写收入说明后保存
